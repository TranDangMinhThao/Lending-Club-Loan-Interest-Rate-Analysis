# Lending Club Loan Interest Rate Analysis

## Project Overview
This academic group project analyzes Lending Club loan data to investigate factors associated with loan interest rates using statistical analysis and machine learning techniques.

## Dataset
- 2.26M+ loan records
- 151 original attributes

## My Contribution
As a team member, I was responsible for:
- Data preprocessing and feature selection
- Missing-value handling
- Outlier handling
- Categorical encoding
- Exploratory Data Analysis (EDA)
- Feature engineering
- OLS regression modeling
- Statistical diagnostics, including Shapiro-Wilk testing and Variance Inflation Factor (VIF) analysis

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Statsmodels
- Scikit-learn
